# Promoted kennel logos

Store each approved logo inside `media/kennels/DI-K-000000/` using the matching kennel ID.

- Preferred: transparent SVG.
- Accepted: transparent PNG or WebP.
- Supply a clean monochrome version whenever possible.
- Activate the placement only after the logo, destination and 12-month term are recorded in `data/promotion-belt.json`.

Paid placements use equal dimensions and rotation rules. The belt is hidden while no active placements exist.
